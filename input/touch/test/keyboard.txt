# Экранная клавиатура svkbd: левая кнопка зажата, пока палец на клавише.
# До прогона: xterm в фокусе, строка ввода пустая, svkbd на слое en.
#
# Ждём в журнале только «клавиатура: нажато / отпущено», ни одного «правый
# клик»; на снимках — выбор è é ê … в верхнем ряду, после выбора — é в
# строке ввода; в конце строка снова пустая.

# Тап по q — печатает q.
d 0 1 109 768
s
w 80
u 0
s
w 500
# Удержание Backspace 2,5 с — повтор стирает q (и всё, что было в строке).
d 0 2 972 911
s
w 2500
u 0
s
w 500
# Удержание e 1,5 с — svkbd показывает выбор è é ê ë ę ē ė ě; он остаётся и после отрыва пальца.
d 0 3 284 768
s
w 1500
x DISPLAY=:0 scrot -o overlay.png && echo "снимок: overlay.png"
u 0
s
w 500
# Тап по é в выборе — печатает é, выбор прячется.
d 0 4 127 695
s
w 80
u 0
s
w 500
x DISPLAY=:0 scrot -o picked.png && echo "снимок: picked.png"
# Тап по Backspace — стирает é.
d 0 5 972 911
s
w 80
u 0
s
w 500
